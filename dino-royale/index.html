Dino Royale

A multiplayer dinosaur combat game by Dinosaur Inc

About the Game

Dino Royale is an independent, in-development multiplayer dinosaur combat game featuring playable dinosaurs, free-for-all battles, team battles, AI-controlled dinosaurs, survival mechanics, and online multiplayer. Dino Royale is not yet released and is not currently available for purchase.

Developer

Dino Royale is developed by Dinosaur Inc, an independent game development effort.

Online Services

Dino Royale uses Epic Online Services and Epic Account Services to power its online multiplayer and account-related functionality. When a player signs in with an Epic Account, the game may request permission to access:

  • Basic Profile
  • Friends List
  • Presence

These permissions are used for authentication, multiplayer sessions, and friend/social features within the game. Dino Royale is an independent project and is not affiliated with, endorsed by, or sponsored by Epic Games, Inc.

See the Dino Royale Privacy Policy for more detail on how information is used.
